
1. Criar um pequeno banco de dados de nome "Locadora".

2. Criar as tabelas descritas no dicionário de dados abaixo.

3. Crie as constraints para atender ao que for especificado no dicionário de dados.

4. Inserir os dados relacionados.

5. Insira alguns registros na tabela Filme_Ator.

6. Alterar a duração do filme Triplo X de 180 para 200.

7. Alterar a categoria do filme Connan de Ação para Aventura.

8. Apagar o tipo de participação cujo identificador seja 2.

9. Apagar todos os filmes que tenham duração acima de 410.

10. Crie uma tabela de nome "Controle_Exclusao". Os atributos desta tabela são:
IDExclusao, IDFilme, IDAtor e IDTipo.
